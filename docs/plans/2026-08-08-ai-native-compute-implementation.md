# AI-Native Compute Blog Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a styled interactive Mermaid renderer to Markdown posts and publish an editable, illustrated post about determinism in AI-native compute.

**Architecture:** Keep authored content in `public/blog/*.md`. Convert only Mermaid fenced code blocks into placeholder elements while parsing Markdown, then mount React diagram viewers into those placeholders after article HTML is present. Store referenced paper figures as local static assets and retain attribution in the post.

**Tech Stack:** React 17, react-router-dom 6, marked, Mermaid 11, react-super-mermaid, CSS.
